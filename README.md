# داتا سوق · DataSouq

سوق بيانات وحلول رقمية — صفحة واحدة بتعرض المنتجات وبتوجّه الطلبات مباشرة على **واتساب**،
من غير سلة شراء ولا بوابة دفع ولا باك-إند.

🔗 **الموقع:** https://datasouq.github.io

---

## المميزات

- 🎨 نظام تصميم مستوحى من **Supabase** — ثيم داكن افتراضي + وضع فاتح بزر تبديل
- 🛒 عرض المنتجات في شبكة كروت مع نافذة تفاصيل لكل منتج
- 🔍 بحث فوري + فلترة بالتصنيف + ترتيب بالسعر أو الاسم
- 💬 كل زر "اطلب" بيفتح واتساب برسالة جاهزة فيها اسم المنتج وسعره ورابطه
- 📱 متجاوب بالكامل مع الموبايل
- 🌍 عربي بالكامل باتجاه RTL
- ⚡ HTML/CSS/JS خام — من غير build ولا dependencies

## ⚙️ الإعداد المطلوب

### ١. رقم الواتساب

افتح [`assets/js/config.js`](assets/js/config.js) وغيّر:

```js
whatsappNumber: "201000000000",   // ← رقمك هنا
showPlaceholderWarning: false,    // ← خليها false بعد التغيير
```

**صيغة الرقم:** كود الدولة + الرقم، من غير `+` ولا صفر في الأول ولا مسافات.

| الدولة | المثال |
|---|---|
| مصر 🇪🇬 | `201012345678` |
| السعودية 🇸🇦 | `966512345678` |
| الإمارات 🇦🇪 | `971501234567` |

### ٢. المنتجات

افتح [`assets/js/products.js`](assets/js/products.js) وعدّل مصفوفة `PRODUCTS`.
كل منتج بالشكل ده:

```js
{
  id: "my-product",              // معرّف فريد بالإنجليزي (بيبقى رابط المنتج)
  name: "اسم المنتج",
  category: "قواعد بيانات",       // لازم يطابق واحد من CATEGORIES
  price: 2500,                   // رقم | 0 = مجانًا | null = "حسب الطلب"
  oldPrice: 3200,                // اختياري — بيظهر مشطوب
  badge: "الأكثر طلبًا",          // اختياري
  glyph: "🏢",                    // إيموجي بديل للصورة
  image: "",                     // أو "assets/img/product.jpg"
  description: "وصف قصير سطرين.",
  details: "الوصف الكامل في نافذة التفاصيل.",
  tags: ["وسم", "وسم تاني"],
  specs: { "المواصفة": "القيمة" },
  featured: true                 // يظهر في الأول
}
```

التصنيفات نفسها بتتعدّل من مصفوفة `CATEGORIES` في أول نفس الملف.

### ٣. الصور (اختياري)

حط الصور في `assets/img/` وحط مسارها في حقل `image`.
لو سيبته فاضي هيظهر الإيموجي بتاع `glyph` على خلفية متدرّجة.

## التشغيل محليًا

```bash
python -m http.server 8000
```

وبعدين افتح `http://localhost:8000`.

> ملاحظة: لازم سيرفر محلي — فتح `index.html` مباشرة بالمتصفح ممكن يمنع تحميل ملفات JS.
